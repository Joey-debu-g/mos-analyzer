# 代码说明与阅读路线

## 软件如何工作

CSV 文件 → read_table 解析表头和数据行 → make_curves 选择列、分组、统一单位、排序 → analyze 计算参数 → app.py 绘图和生成报告 → 导出文件。

## 建议先读 core.py

`Curve` 是一条曲线的数据容器，包含名称、以伏特表示的 x 数组、以安培表示的 y 数组。数据读取与算法不依赖窗口，便于独立测试。

`read_table(path)` 先读取字节，尝试 UTF-8、GB18030，再检测分隔符。它只读取表格，不猜测物理量。重复或空列名会导致错误，避免选错数据。

`make_curves(...)` 把所选列转换成浮点数，乘以单位系数，再根据分组值整理。例如 2 mA 乘以 0.001，得到 0.002 A。每组按电压升序排列，并检查重复电压和无效数字。不能仅靠排序处理回滞，应由使用者正确分组。

`derivative(x,y)` 求 gm。对内部点 i，令 a=x[i]-x[i-1]、b=x[i+1]-x[i]：

```text
gm[i] = -b/(a*(a+b))*y[i-1]
        + (b-a)/(a*b)*y[i]
        + a/(b*(a+b))*y[i+1]
```

它来自通过三个点的二次插值多项式求导，所以可用于不等间距采样。当间距相等时，简化为中心差分 `(y[i+1]-y[i-1])/(2h)`。端点没有两侧邻点，改用割线斜率。端点精度较低，因此阈值提取不把端点当候选峰值。

`constant_current(x,y,target)` 找到目标电流两侧的采样点，做直线插值。它要求电流单调不减，以避免多次交叉时默默选一个结果。例如 (0 V,0 A)、(1 V,2 A) 两点间，1 A 对应 0.5 V。实际判据应远小于这个教学数字。

`analyze(curve,target,vds)` 把上述计算组合起来。线性外推的第一步是以最大 gm 点的切线延长至 Id=0，得到 `Vgs_peak-Id_peak/gm_peak`，再减去 Vds/2。输入负电流、非正 Vds 会拒绝；非单调曲线不提取外推值。结果字典同时包含数值和提示。

## 再读 app.py

`Application` 继承 Tk 窗口。`build_ui()` 创建按钮、下拉框、输入框、绘图区域和报告区域。

`load()` 读取文件，并填充列选择框。加载自带示例时自动绘图；外部文件需用户确认列和单位后分析。

`run()` 读取设置，验证数据，调用 core 模块，更新两张图与报告。输出特性只绘制 Id–Vds，转移特性同时绘制 gm–Vgs。

`snapshot` 保存成功分析时的设置。`export()` 比较当前设置与 snapshot，防止修改条件后误导出之前的结果。导出文件包含原始文件路径、单位、判据、Vds、参数和提示，方便复现。

`report_text()` 把结果变成中文报告。参数字段中的 `_V`、`_A`、`_S` 表示物理单位，`CC` 表示恒流法，`ELR` 表示线性区外推法。

## 新增的界面功能如何实现

`ChineseToolbar` 继承 Matplotlib 的 Tk 工具栏，保留原来的导航历史和模式切换逻辑，将按钮显示为中文文字，并提供中文悬停提示。`scale_view()` 先把坐标范围转换到坐标轴的尺度空间，再围绕中心调整范围，最后转换回来；所以对数坐标的缩放不会直接把电流下限缩成负数。放大缩小均写入导航历史，可以后退、前进和恢复全图。

`make_table()` 创建带横向和纵向滚动条的 Treeview 表格；`fill_table()` 设置列名和数据。导入时预览前 100 行原始文本，分析后 `update_results()` 按转移或输出模式选择中文列标题与单位，不会把输出曲线的结果混入阈值列。

`annotate_analysis()` 使用与 core.analyze 相同的内部最大跨导点，在转移图上绘制恒流交点、外推切线、零电流截距和修正阈值，在跨导图上标记峰值并显示外推阈值。切线的零电流截距为 `Vth_ELR + Vds/2`，与修正阈值是两个不同位置。对数坐标隐藏零电流截距和切线，三角标记采用轴坐标固定高度，横坐标仍是真实阈值。

`settings_changed()` 监听设置变化，对旧结果明确标注；分析失败会清空旧图和旧表，防止用户把之前的结果误认作本次输出。

## 如何扩展

新增算法先放在 core.py，用已知答案的数据验证，再在 app.py 添加控件和结果展示。进一步扩展器件极性时应保持明确的电压、电流符号约定，不能简单对所有数据取绝对值。新增平滑需要让用户看到平滑方法和窗口，并保留原始曲线，防止掩盖测量问题。


## 第二批实现结构

`Application.datasets` 是文件列表，每项包括 source（原始来源标识）、headers（列名）、rows（原始文本行）和 config（该文件的分析设置）。`active` 是当前正在编辑的文件。`select_dataset()` 切换编辑对象并更新预览；`switching` 暂停变量监听，避免把新文件设置写入旧文件。设置变化由 `settings_changed()` 写回当前文件。

`current_settings()` 对全部文件的设置取副本，构成成功分析时的 snapshot。只切换当前编辑文件不让结果失效；真正修改某个文件的配置、增删数据后会要求重新分析。

`run()` 调用 `analysis.analyze_datasets()` 获得所有文件的曲线、结果和跨导，然后更新图表与表格。分析流程与窗口交互分开，便于独立阅读。

`analysis.py` 中的 `prepare_curves()` 应用单个文件的列映射、单位和器件极性；单位系数集中在 `VOLTAGE_SCALES`、`CURRENT_SCALES` 中。`analyze_datasets()` 遍历文件，调用 core.py 中的原有算法并汇总结果。文件序号作为曲线名称前缀，结果和导出同时保留来源标识与极性。出错时保留文件序号和名称，供窗口提示。

`normalize_curve()` 只执行明确的极性变换：NMOS 的电压、电流保留，PMOS 同时乘 −1，再按正的控制电压排序。若变换后仍为负则报错。`analyze_device()` 对归一化曲线使用原有算法，PMOS 的阈值、峰值栅压转换回带符号的 Vgs，Vds 保留原始符号。跨导保持正向导通时的斜率。

`project.py` 独立负责 `.mosproj` 格式校验和存储。文件包含原始数据副本，不保存可执行 Python 对象。读取失败不会替换当前数据。写入先生成同目录临时文件，再用原子替换提交完整内容；版本字段方便以后升级格式。

`test_second_batch.py` 验证 PMOS 的已知阈值、符号拒绝、多文件不同列名/单位/偏置、配置切换、源 CSV 缺失时的项目恢复、导出的带符号数据、损坏项目保留当前状态，以及 PMOS 输出特性。

## 本次小范围代码整理

多文件分析移至 analysis.py；界面和操作流程保持原样。数据预览、结果表和报告的复杂表达式改为分步处理；`format_parameter()` 统一表格数字格式及“未提取”文本。计算公式、项目格式和导出列定义没有调整。

验证包括 16 项现有测试，以及修改前后五组示例的逐值对比：NMOS 转移、NMOS 输出、PMOS 转移、PMOS 输出、NMOS/PMOS 多文件对比。全部参数、曲线采样点和跨导数据一致。
