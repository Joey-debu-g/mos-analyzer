# MOS 器件特性数据分析软件 V1.0

这是首个可验收的 Python 桌面版本，面向集成电路课程中的 NMOS/PMOS 数据分析，支持多文件对比和便携项目保存。用户提供仿真或测量导出的 CSV；软件本身不执行 SPICE 仿真。暂不支持自动偏置识别、噪声平滑或器件模型拟合。

## 启动

当前电脑已具备 Python、Tkinter、Matplotlib。双击 `启动软件.bat`，或在本目录执行：

```powershell
python app.py
```

其他电脑需要带 Tkinter 的 Python 3.10 或以上版本，并执行 `python -m pip install -r requirements.txt`。本阶段为源码运行版，尚未提供独立 EXE。更新代码后须关闭旧窗口并重新启动。

## 先用示例验收

1. 点击“转移示例”：显示两条 Id–Vgs 曲线和对应 gm 曲线。
2. 保持 Vds=0.05 V、恒流判据=1e-6 A。NMOS_A 的跨导峰值应约为 1e-4 S，NMOS_B 约为 8e-5 S；线性外推阈值均应接近 0.45 V。
3. 点击“输出示例”：显示五种 Vgs 下的 Id–Vds 曲线；输出特性模式不提取跨导或阈值。
4. 点击“导出结果”，选择名称，生成同名 JSON 参数文件、CSV 分析数据、PNG 图和 TXT 报告。
5. 修改任一设置后，须重新分析才能导出，避免导出旧结果。

示例是理想长沟道模型生成的合成数据，**不是实际器件测量或实际 SPICE 仿真结果**。模型参数 beta=0.002 A/V²、Vth=0.45 V，未包含沟道长度调制、迁移率退化等效应。生成脚本为 `generate_examples.py`。

## 导入自己的数据

导入外部文件后，下方自动切换到“原始数据预览”，显示前 100 行及全部列。预览中的“数据行”按表头占第一行计算；数值保留导入文本，不提前换算单位。请结合预览选择上方的电压列、电流列、分组列和单位，确认后再分析。

第一行必须是唯一且非空的列名，后续为数字，支持逗号、分号或制表符分隔，支持 UTF-8 和 GB18030 编码。例如：

```csv
Vgs,Id,device
0.0,1e-12,A
0.1,1e-12,A
0.2,1e-12,A
```

导入后选择电压、电流、分组列及原始单位，点击“绘图 / 重新分析”。界面默认映射前两列为电压、电流，第三列为分组；这是便捷默认值，必须自己核对。没有分组时选择“不分组”。每组至少三个不同电压点，软件按电压排序；重复电压会报错，因此回扫数据应拆成不同组。每个文件的转移曲线分组须使用同一 Vds；不同 Vds 的扫描请放在不同文件中，再分别设置偏置。

支持 V、mV，以及 A、mA、uA、nA。内部计算与导出使用 V、A、S；导出 CSV 同时记录显示用的幅值和带符号的端口数据。不得在单元格内写单位，例如 `1uA`；应写数字并在界面选择单位。空值、NaN、无穷大会报错。NMOS 使用非负电压和 Id；PMOS 使用非正的 Vgs/Vds 和 Id，不能把幅值正数直接当作带符号 PMOS 数据导入。对数坐标要求归一化后的电流幅值严格大于零。

## 参数含义与适用条件

- gm = dId/dVgs：内部点采用适用于非等间距采样的三点差分，端点采用单侧割线；参数峰值从内部点选择。采样稀疏和噪声会影响结果，首版不自动平滑。
- 恒流法 Vth_CC：在用户指定的绝对电流处线性插值；未按 W/L 归一化。判据不在范围内、曲线非单调或判据落在平台时不输出阈值。
- 线性外推 Vth_ELR：取内部最大跨导点，计算 `Vgs - Id/gm - Vds/2`。该方法针对低漏压的转移扫描，每组必须固定 Vds，并需由用户确认器件工作条件。软件会提示 Vds>0.1 V、峰值接近边界及阈值超出扫描范围；这些提示不能代替物理有效性判断。
- 输出模式只绘制 Id–Vds 并给出最大电流，不将 dId/dVds 错当跨导。

方法参考：[Keysight：MOSFET Threshold Voltage Extraction](https://www.keysight.com/blogs/en/tech/sim-des/mosfet-threshold-voltage-extraction)。恒流法判据及线性外推对偏置、噪声、寄生电阻与迁移率退化敏感，两种方法不保证得到相同结果。

## 中文图表操作和结果查看

- “放大”“缩小”：点击即以当前视图中心缩放所有子图；对数坐标也可以使用。
- “恢复全图”：回到本次分析初始视图。“后退”“前进”在本次分析的缩放、平移历史中切换；重新分析后历史重置。
- “平移”：点击开启，在图内左键拖动；再次点击退出。“框选放大”：左键框选放大、右键框选缩小，再次点击退出。鼠标悬停按钮可查看中文提示。
- “保存图片”：仅保存当前图。上方“导出结果”仍保存四类文件。
- 下方“分析结果”用中文表格展示参数和单位，长提示可横向滚动查看。“原始数据预览”“详细报告”可随时切换；中间分隔条可拖动调整图表与表格高度。
- 修改设置后，表格会提示其为上次结果，并禁止导出；重新分析成功后更新。分析失败则清空旧曲线和旧参数。

转移曲线标记：圆点为恒流判据交点；菱形为实际选取的最大跨导点；虚线为该点切线；叉号为切线在零电流处的截距；下三角为减去 Vds/2 后的外推阈值，其纵向位置只是标记排布，不代表电流。外推阈值数值显示在跨导子图及结果表中。

对数电流坐标下，零电流无法显示，因此隐藏外推切线和零电流截距，只保留恒流交点、跨导峰值和修正阈值位置。无有效阈值时，不绘制对应标记。理想示例的切线可能与原曲线重叠，这是模型在线性区斜率恒定导致的。

## 第二批功能：多文件对比、项目和 PMOS

### 多文件对比

1. “打开 CSV”替换整个数据集；“添加 CSV 对比”可一次多选并追加文件。示例按钮也会替换整个数据集。
2. 在“当前文件”下拉框逐个选择文件，核对原始数据预览，设置各自的电压列、电流列、分组列、单位、器件类型、恒流判据和 Vds。
3. 点击“绘图 / 重新分析”，所有文件叠加绘图，结果表保留器件及源文件列。曲线名称以文件序号和文件名区分，即使不同文件同名也能区分。
4. 曲线类型与对数坐标为全局设置；一次对比必须全为转移特性或全为输出特性。每个文件只能指定一种器件极性及一种转移扫描 Vds。
5. “移除当前文件”仅从软件当前项目中移除，不删除磁盘 CSV。添加、移除后需重新分析。任一文件分析失败时整次分析清空，不会悄悄遗漏错误文件。

### 项目保存和恢复

“保存项目”生成 `.mosproj`，它是带格式版本的 JSON，包含所有原始数据行、列名、来源标识、每个文件的设置、全局模式、对数坐标和当前文件索引。项目采用临时文件写入再替换，减少写到一半损坏原项目的风险。

“打开项目”先校验文件结构，再恢复数据与设置；不依赖原 CSV 路径，也不执行项目内容。恢复后点击“绘图 / 重新分析”重新生成结果。损坏或不支持的项目会报错并保留当前项目。项目不保存窗口尺寸、导航历史或人工缩放状态；导出结果 JSON 与项目文件用途不同，不能用来恢复项目。

保存前请确认设置。项目含原始数据副本和源文件标识，发给别人时也会携带这些内容。打开 CSV、示例或其他项目会替换当前数据集；如需保留已有设置，应先保存项目。

### PMOS 的符号和结果

PMOS 输入采用以源极为参考的带符号端口数据：Vgs≤0、Vds≤0、Id≤0。转移分析中的 Vds 必须严格小于零，恒流判据仍填写正的电流幅值。若仿真器导出的电流方向相反，请依据该仿真器端口定义先转换符号，软件不会自动猜测。

内部把 `Vsg=-Vgs`、`Vsd=-Vds`、`I=-Id` 转到正值域，按 Vsg/Vsd 排序后分析。显示 NMOS 的 Vgs/Vds、Id 与 PMOS 的 Vsg/Vsd、-Id，可同图对比幅值；表中的 PMOS 阈值、峰值栅压和 Vds 返回原始负号。gm 为正向导通条件下的 dId/dVgs，与幅值域的 d(-Id)/dVsg 相同。输出表中的最大电流是幅值。

PMOS 外推幅值公式为 `|Vth| = Vsg_peak - I_peak/gm_peak - Vsd/2`，最终报告 `Vth=-|Vth|`。图中三角阈值位置是幅值，旁边数字及表格是带符号的阈值；输入符号不符合约定会拒绝分析。模型适用条件与 NMOS 一样，必须核对低漏压、固定偏置和数据质量。
